# 구현 계획: 메뉴별 작업 블록

**상태: 사용자 승인 후 구현 완료.**

**명세**: `.claude/prds/work-card-clarity.prd.md`

1. 기존 `Note` 카드와 주문서 전체 완료 흐름을 분리하고, 주문별 메뉴 줄의 제조 완료 상태를 `teamktb` 저장소에 둔다.
2. `aiserver`가 기존 메뉴 쌍 점수로 함께 제조 가능한 메뉴 ID를 반환하도록 확장한다. `teamktb` 응답 파서와 계약 테스트를 맞춘다.
3. 검증한 메뉴 ID와 레시피로 순서가 분명한 작업 블록·주문별 수량·짧은 제조 키워드를 계산한다. `/api/notes`에서 블록 하나를 완료하면 해당 주문들의 메뉴 줄만 제조 완료 처리하고, 대시보드의 아래 블록과 위 주문서 줄에 완료 표시를 둔다.
4. 주문서 완료 시 함께 만들 주문 전체의 `made` 상태를 자동 변경하는 연결을 제거한다. 빠른 주문 처리는 유지한다.
5. `app/domain/scenarios.ts`에 메뉴별 제조 시연 장면을 추가한다. 부분 완료, 주문서와 작업의 독립성, 복합 주문의 메뉴 선택, 묶음 변경, Zoro 실패 상태를 테스트한다. Zoro 대역 서버를 이용해 실제 화면까지 실행하고 양쪽 테스트·타입 검사를 실행한다. README와 API 계약 문서의 실행·확인 방법도 갱신한다.
